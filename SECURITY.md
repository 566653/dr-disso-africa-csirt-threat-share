# Security Policy / Politique de sécurité

FR : Prototype de triage défensif. Ne publiez aucune donnée personnelle, preuve judiciaire ou information classifiée dans les tickets publics. Signalez les vulnérabilités en privé à l'administrateur. Audit indépendant obligatoire avant toute production.

EN: Defensive triage prototype. Never submit personal data, criminal evidence or classified material to public issues. Report vulnerabilities privately to the maintainer. Independent audit required before production.

No SLA or security certification is claimed.
